# Примитивы — рецепты

Каждый рецепт = размеры + состояния + правило использования. Классы — из `docs/design/assets/reference.css`; в React повторяйте те же значения через токены и варианты `apps/web/src/components/ui/*`.

## Карточка `.card`

- `surface`, радиус 20, `shadow-card`, без border. Padding 20.
- Шапка: заголовок `text-title` + опционально (i); подзаголовок `text-body` `ink-3` «что здесь», отступ 2. Справа — максимум одно действие (ghost `sm`) или статус.
- Вложенные блоки — `surface-2`, радиус 12, без тени.
- На `surface`-листе карточка не нужна: группируйте секцией с заголовком и отступом 32. Карточка на карточке — ошибка.

## Кнопки `.btn`

| Вариант   | Фон / текст                                   | Когда                                                                  |
| --------- | --------------------------------------------- | ---------------------------------------------------------------------- |
| primary   | `accent` / `accent-ink`, hover `accent-hover` | Одно главное действие на экране                                        |
| secondary | `surface-2` / `ink`, hover `surface-3`        | Обычные действия                                                       |
| ghost     | прозрачный / `ink-2`, hover `surface-2`       | Тулбары, шапка треда, «Cancel»                                         |
| danger    | `danger-soft` / `danger`                      | Вход в удаление. В финальном подтверждении — сплошной `danger` + белый |

- Высота 36 (`sm` — 28, текст 12). Padding 0 16 (`sm` — 0 12). Радиус pill. Вес 500.
- Иконка 16 слева, отступ 8. Иконочная кнопка — круг 36/28, обязателен `aria-label` и тултип с названием (+ клавиша, если есть).
- `:active` → `scale(.97)`. Disabled → opacity .45, без событий; если причина неочевидна — тултип «почему».
- Загрузка: спиннер 14 вместо иконки, текст в процессе («Pushing…»), кнопка заблокирована.
- Текст — глагол + объект: «Create PR», «Add project», «Restore checkpoint». Не «OK», «Yes», «Submit».
- В модалке: справа, порядок `ghost Cancel` → `primary/danger Действие`.
- Сплит-кнопка (Commit ▾, Open in ▾): основная часть + шеврон 28 на том же фоне через зазор 2.

## Поля

- `.input` / `.select`: высота 36, padding 0 12, `surface-2`, радиус 12, без border. Hover → `surface-3`. Focus → фон `surface` + `inset 0 0 0 1px accent` + `0 0 0 4px accent-soft`.
- Ошибка: `aria-invalid` → `inset 0 0 0 1px danger`, фон `surface`; подсказка под полем красная и говорит, **как исправить**.
- `.field`: подпись (`text-body`/500, + (i) если термин) → поле → подсказка (`text-caption` `ink-3`).
- Поиск: лупа 16 слева (padding-left 36), крестик очистки справа, клавиша-подсказка `kbd` справа, пока поле пустое.
- Значения-код (путь, команда, URL, ветка) — поле `font-mono` `text-code-sm`.
- Textarea: min-height 88, padding 10 12.
- Необязательное поле: «· optional» в подписи.

## Сегменты `.seg`

- Контейнер `surface-2`, padding 3, gap 2, pill. Кнопки 28 (`sm` 24), padding 0 12, `ink-3`/500.
- Выбранная: `surface`, `ink`, `shadow-raised`.
- Для 2–4 взаимоисключающих вариантов (тема, режим диффа unified/split). Больше 4 → селект или меню.

## Табы панели `.ptabs`

- Вкладки правой панели и разделов (Diff / Terminal / Preview / Files): высота 32, pill-плашки, `ink-3`/500; активная — `surface-2` + `ink`. Счётчик — `text-caption` `ink-3` после названия.
- Закрываемая вкладка — крестик 14 при hover.

## Бейджи и чипы

- `.badge`: высота 20, padding 0 8, pill, `text-caption`/500. Нейтральный `surface-2`/`ink-2`. Статусные мягкие — с точкой 6.
- `.chip` (контекст композера, ветка, окружение, файл): высота 24, padding 0 8 0 6, pill, `surface-2`, иконка 14 `ink-3`, текст `text-code-sm` для путей/веток или `text-caption` для слов, крестик 14 при hover если удаляемый.
- Метки «New» / «Beta» — мини-бейдж 18 `accent-soft`.

## Статус агента `.status`

- Пилюля 22, padding 0 8 0 6, `text-caption`/500: иконка 14 + слово (+ время). Цвет и иконка — из `patterns.md` «Статусы агента».
- Компактная форма в строке сайдбара — точка 8 (`working` — спиннер 12, `needs-you` — точка `attention` с кольцом `attention-soft` 3px).

## Переключатель и выбор

- Switch: 36×20, pill, выкл `surface-3`, вкл `accent`, кружок 16 белый с тенью, пружина 220 мс. Применяется сразу, без «Save». Слева заголовок + подсказка, переключатель справа.
- Checkbox: 16, радиус 6, выкл `surface-2` + `inset 0 0 0 1.5px ink-4`, вкл `accent` + белая галочка.
- Радио-карточки `.choice`: когда у вариантов есть последствия (режим доступа агента, тип окружения). Плитка `surface-2`, радиус 12, padding 14 16, заголовок 600 + пояснение `text-caption` `ink-3`. Выбранная — `accent-soft` + `inset 0 0 0 1px accent`.

## Подсказка (i) и тултип

- (i): кружок 18, иконка 14 `ink-4`, hover `ink-2` на `surface-2`. Сразу после термина в той же строке. Ставится у настроек и терминов, смысл которых не очевиден разработчику (Worktree mode, Full access, Checkpoint).
- Тултип: `inverse` фон, радиус 8, padding 6 10, max-width 280, `text-caption`. С (i): первая строка — **название**, дальше 1–2 предложения. У иконочной кнопки — название + `kbd`.
- Появление: задержка 300 мс, сдвиг 4 + opacity за 150 мс.

## Клавиши `.kbd`

- Высота 20, min-width 20, padding 0 5, радиус 6, `surface-2`, `text-code-sm`/500 `ink-3`. Комбинация — отдельные `kbd` без «+» (`⌘` `K`). На Windows/Linux — `Ctrl` `K`.

## Аватар и знак провайдера

- Знак провайдера (Codex, Claude, Cursor, Grok, OpenCode, Antigravity): логотип в круге `surface-2`, размеры 16 / 20 / 28 / 40, монохром `ink-2`; цветной логотип — только в выборе провайдера и в настройках провайдера.
- Аватар человека/устройства: фото или инициалы (до 2 букв, 600) на `surface-3`; ошибка загрузки → инициалы.
- Монограмма проекта: квадрат радиус 6 (на 16) / 8 (на 28), `surface-3`, первая буква 600; фавикон проекта, если есть.

## Поповер, меню `.pop`

- `surface`, радиус 12, `shadow-pop`, padding 4, отступ от триггера 6. Появление 150 мс: opacity + translateY(−4) + scale .98. Закрытие: клик мимо, Esc, выбор.
- Пункт всегда в одну строку: длинная подпись обрезается многоточием, мета и клавиши справа не сжимаются. Перенос на вторую строку внутри фиксированной высоты — дефект.
- Пункт `.opt`: высота 32, поля 0 10, радиус 8, hover `surface-2`. Иконка 16 `ink-3` слева, мета/`kbd` справа `ink-3`. Выбранное — галочка 16 `ink` справа (не акцент).
- Разделитель 1px `line`, отступ 4. Подзаголовок группы `text-caption`/500 `ink-3`, padding 8 8 4, без капса.
- Опасный пункт — последним, после разделителя, `danger`.
- Выбор модели/провайдера: поиск сверху, группы по провайдеру, знак провайдера 16 + название модели + мета (`text-caption` `ink-3`: «fast», «1M context»).

## Баннер `.alert`

- Радиус 12, padding 12 16, иконка 16 слева. Заголовок 600 + текст `ink-2`. Действие справа (кнопка `sm`).
- `notice` — `surface-2` + иконка `working`. `warning` / `danger` / `success` — мягкий фон своего цвета.
- Только когда проблема мешает работе (нет соединения с окружением, провайдер не авторизован, обновление требует перезапуска). Всегда объясняет последствие и даёт действие.

## Тост

- Снизу справа (на телефоне — снизу по центру), ширина 360, стек с зазором 8. Фон `inverse`, радиус 12, `shadow-pop`, padding 12 14. Иконка 16 (галочка `success` / треугольник `danger` / спиннер для идущего), заголовок 500 + пояснение 12 opacity .7.
- Живёт 5 с, при наведении — пауза. Для удаления/архивации — «Undo». Для ошибки — «Retry».
- Тост подтверждает сделанное или сообщает о фоне (тред закончил работу). Ошибки валидации — под полем, не тостом.

## Модалка и шторка

- Оверлей `rgba(20,18,16,.32)` + blur 2px. Модалка ширина 480 (`wide` 600, `xwide` 760), радиус 28, `shadow-pop`, появление translateY(8)+scale .98 → 1 за 220 мс. Закрытие: Esc, клик по фону, крестик (ghost иконка `sm`).
- Структура: шапка (padding 24 24 0: `text-heading` + описание `ink-3`) → тело (padding 20 24, зазор 20) → низ (padding 0 24 24, кнопки справа).
- Подтверждение удаления: иконка 40 в `danger-soft` круге, заголовок вопросом с именем («Delete “fix-auth-flow”?»), текст **перечисляет, что пропадёт**, кнопка «Delete thread» сплошным `danger`.
- Шторка справа — детали (PR, окружение): ширина 420, отступ 8 от краёв окна, радиус 28, сдвиг 24 справа. На узком экране — снизу на всю ширину, ручка 36×4.

## Прогресс, шаги, загрузка

- Прогресс: высота 6, pill, фон `surface-2`, заливка `accent` (`attention` у лимита). Над ним подпись + число справа (`tabular-nums`).
- Шаги мастера: кружок 24, линия 2. Пройден — `accent` + галочка, текущий — `accent-soft` + кольцо `accent`, будущий — `surface-2`.
- Скелетон — форма итогового блока, статичный `surface-2` **без шиммера** (закон 7).
- Спиннер 14, `currentColor`, только пока идёт процесс.

## Пустые состояния

- `.empty` (страница / панель / карточка): плитка 44 радиус 14 иконка 20 → заголовок `text-title` до 5 слов → строка `ink-3` до 12 слов → одна кнопка. Цвет плитки по типу (`patterns.md`).
- `.empty-row` (поповер, палитра, список): одна строка `text-caption` `ink-3` «No threads match “auth”.», padding 16 12, без плитки.

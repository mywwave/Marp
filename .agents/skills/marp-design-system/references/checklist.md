# Чек-лист перед сдачей UI

Пройдите каждый пункт. Пункт не выполнен → исправьте, а не объясняйте.

## Сверка с эталоном

- [ ] Нашёл ближайший образец в `docs/design/reference.html` или эталоне раздела и повторил разметку и токены.
- [ ] Поставил свой экран и эталон (`?frame=1#экран`) рядом на тех же размерах и сравнил отступы, шрифты, радиусы.

## Поверхности и цвет

- [ ] Ни одной рамки у карточек, полей, кнопок, сообщений, блоков кода (исключение — зона перетаскивания файла).
- [ ] На экране одна primary-кнопка. Акцент не используется для декора, ссылок и статусов.
- [ ] Все цвета из токенов. Нет hex, `rgb()`, `text-gray-*`, `bg-white`.
- [ ] Проверено в 2 темах × 2 акцента (Глина + Лес). В тёмной теме нет белых пятен, тени заменены кольцом.

## Типографика, код, числа

- [ ] Только размеры шкалы (12/13/15/18/22/30, код 12/13) и веса 400/500/600.
- [ ] Текст сообщений 15/24, колонка не шире 760.
- [ ] Код, пути, команды, ветки, клавиши — моно. Пути обрезаются посередине, имя файла видно.
- [ ] `tabular-nums` только в колонках, таймерах и номерах строк.

## Статус и честность

- [ ] Статус агента по таблице `patterns.md`: семейство, цвет, иконка, слово.
- [ ] Спиннер/«Working» только пока процесс жив; после ошибки или остановки статус меняется сразу.
- [ ] Бесконечное — только спиннер и шиммер живой работы (один на процесс, `transform` шагами); нет пульсов и градиентов; `prefers-reduced-motion` учтён.

## Объяснения и тексты

- [ ] Неочевидные настройки и термины — с (i).
- [ ] Пустое состояние по типу и размеру из `patterns.md`; одна кнопка или ни одной; в поповере — строка без плитки.
- [ ] Ошибки говорят, что делать. Кнопки называют действие. Sentence case, без капса.

## Состояния

- [ ] hover, focus-visible, active, disabled — у всех интерактивных элементов.
- [ ] loading — скелетон той же формы с шиммером или спиннер в кнопке.
- [ ] empty, error — внутри блока, с действием.
- [ ] Иконочные кнопки с `aria-label` и тултипом. Поповеры и модалки закрываются по Esc и клику мимо.

## Длинные списки

- [ ] Проверено на 100+ тредах, 50+ шагах работы агента, 40+ файлах диффа: ничего не растёт без предела.

## Поверхности продукта (AGENTS.md «Hit every surface»)

- [ ] Web (локальный и app.t3.codes) и desktop (macOS/Windows: полоса перетаскивания, кнопки окна).
- [ ] Точки входа: кнопка, меню, палитра команд, клавиша — везде одинаково.
- [ ] Провайдеры: решение для каждого адаптера (Codex, Claude, Cursor, Grok, OpenCode, Antigravity).
- [ ] Удалённое окружение и потеря связи.
- [ ] Ширина 1024, 1440, 1920; узкое окно (< 768) не ломает вёрстку.

## Код

- [ ] Использованы примитивы `components/ui` через `variant`/`size`, без перекраски `className`.
- [ ] `vp run check:changed` проходит.

# Рецепты продукта

Как собирать экраны Marp из примитивов. Эталон каждого раздела — `docs/design/<раздел>.html`; здесь — общие правила, которые одинаковы во всех разделах.

## Шелл окна

```
┌ bg ───────────────────────────────────────────────────────────────┐
│ [сайдбар 272, на bg]  ┌ лист surface r20 ──────┐ ┌ панель r20 ──┐ │
│                       │ шапка треда 48         │ │ табы 40      │ │
│                       │ тред (колонка 760)     │ │ дифф/терм.   │ │
│                       │ композер               │ │              │ │
│                       └────────────────────────┘ └──────────────┘ │
└───────────────────────────────────────────────────────────────────┘
```

- Окно — `bg`. Сайдбар лежит прямо на `bg`, без поверхности. Рабочий лист и правая панель — отдельные `surface` радиус 20 с `shadow-card`, зазор 8 между ними и от краёв окна.
- Desktop (Electron): область перетаскивания окна — верхние 40 px `bg`; на macOS сайдбар отступает под светофор (padding-top 40). Кнопки окна Windows — справа в той же полосе.
- Правая панель (Diff, Terminal, Preview, Files) открывается рядом с листом при ширине ≥ 1280, ниже — шторкой поверх листа справа. Ширина тянется за ручку на краю (hover — линия `line` 2px).
- Нижний терминал-ящик внутри листа: отделяется зазором 8 и своей `surface-2` поверхностью радиус 12, не линией.

## Сайдбар

- Ширина 272, padding 8, фон `bg`. Сверху: переключатель окружения/логотип (32) → кнопка «New thread» (secondary, на всю ширину, `kbd` справа) → поиск (по `⌘K` открывает палитру).
- Группа проекта: строка 32 — монограмма/фавикон 16 + имя проекта 500 `ink-2` + шеврон при hover + «+» (новый тред в проекте) при hover. Подпись группы без капса.
- Строка треда: высота 32 (`row-sm`), в режиме двух строк 56 (`row-lg`: заголовок 13/20, ветка 12/16, между ними 2, зазор 6 между строками), на тач-устройствах 56, поля по бокам 12; между проектами 20, радиус 8. Слева статус-индикатор 16 (точка/спиннер/иконка), заголовок `text-body` `ink-2` с обрезкой, справа — относительное время `text-caption` `ink-4` или счётчик. Hover — `surface-2`. Текущий тред — `surface` + `shadow-card`, текст `ink`. Непрочитанный завершённый — заголовок 500 `ink`.
- Действия строки (pin, snooze, archive, rename) — в меню «⋯» при hover и по правому клику; их же видно в палитре команд. «⋯» и время делят один слот справа: при hover время гаснет, «⋯» проявляется (только `opacity`, ширина строки не меняется).
- Полки Working / Snoozed / Settled внизу списка — строки-кнопки 32 (`row-sm`), поля 12, шеврон `ink-4` с зазором 8, счётчик справа; 2 между полками, 16 перед первой. Подписи групп без действия (Projects, Pinned) — 28 (`row-xs`), `text-caption` `ink-3`.
- Мультивыбор (⌘/Ctrl-клик, Shift-клик): выделенная строка — подложка `surface-3` и галочка в кружке акцента вместо точки статуса (не заливка акцентом). Массовые действия — карточка над подвалом высотой 48: «N selected» + иконки Settle, Snooze, Archive, «⋯», сброс (Esc). Перетаскивание: линия вставки 2px акцента от начала текста с кружком, строка-«призрак» смещена и полупрозрачна, чтобы не путаться с текущим тредом.
- В проекте показываем первые 5 активных тредов + «Show N more»; остальное — поиском. Закреплённые — сверху группы, со скрепкой 12 `ink-4`.
- Низ: обновления/уведомления (строки 32 `ink-3`), карточка окружения (знак машины 20 + имя + точка соединения), Settings.
- Свёрнутый сайдбар 56: только иконки 16 в кругах 36, статусы — точками на монограммах проектов.

## Шапка треда

- Высота 48, padding 0 16 0 20, на листе. Слева: заголовок треда `text-title` (клик — переименовать) + статус-пилюля. Под заголовком не пишем ничего — мета живёт в чипах справа.
- Справа ghost-кнопки `sm`: ветка (`chip` с иконкой ветки, mono), окружение, «Open in» (сплит), Git-действия (Commit / Push / Create PR — сплит-кнопка, **secondary**, primary остаётся у композера), тоггл правой панели с `kbd`.
- При прокрутке шапка остаётся; под ней появляется тонкая тень `0 1px 0 line` только когда контент ушёл под неё.

## Тред и сообщения

- Колонка чтения max 760 по центру листа, padding 32 24. Между сообщениями 24.
- **Сообщение пользователя** — справа, плашка `surface-2` радиус 12 (угол справа-сверху 6), padding 10 14, max 85% колонки, `text-read`. Вложения — превью 64 радиус 8 над текстом. Чипы контекста (файлы, PR, треды) — под текстом.
- **Ответ агента** — без плашки, на всю колонку, `text-read` `ink`. Markdown: заголовки 18/600 и 15/600, списки с отступом 20, ссылки `ink` с подчёркиванием `line`→`ink-3` при hover (не акцент), цитата — полоса 2px `line` слева + `ink-2`.
- Над ответом агента — строка автора 20: знак провайдера 16 + модель `text-caption` `ink-3` + время. Повторяется только когда меняется провайдер/модель или прошло больше 10 мин.
- Действия сообщения (Copy, Fork from here, Restore checkpoint) — ghost-иконки 28 под сообщением при hover; на тач-устройствах всегда видны.
- **Чекпоинт** — разделитель между ходами: строка 24, линия `line` + по центру `text-caption` `ink-3` «Checkpoint», пилюля «Changes +N −M» (`outline` xs, тултип «Review changes · 3 files» + `kbd` ⌘E/Ctrl+E) — открывает панель диффа на этом ходе — и ghost «Restore». Это единственная «сводка изменений» хода; отдельной карточки с деревом файлов нет.

## Работа агента (вызовы инструментов)

Как в окне агента Cursor: шаги идут в хронологии между абзацами ответа. Код — `client-runtime/work-log/eventPresentation.ts` (таблица глаголов, правила заголовка), вид — `apps/web/src/components/chat/TimelineWorkEvents.tsx`.

- **Строка шага** 28: иконка 16 `ink-3` + глагол + объект. Глагол из одной таблицы в трёх формах: идёт — «Reading», готово — «Read», ошибка — повелительное «Read» с цветом `danger`. Объект: файл — имя `font-mono` `ink` + папка `ink-3` (+ «L10-60»), поиск — шаблон mono + «in src», MCP — «Ran `create_issue`» с иконкой сервера.
- **Прогон** — шаги между двумя абзацами ответа. Два и больше шагов сворачиваются в одну строку-заголовок `ink-3` с шевроном при hover; первое подходящее правило: только мысли → «Thought for 8s» (или заголовок мысли), браузер → «Ran 3 browser actions», фоновые → «Monitoring background task», только правки → «Edited session.ts» / «Edited 3 files» / «Created …», только команды → описание команды или «Ran 2 commands», иначе «Explored session.ts, 2 searches, 1 command». Пока прогон идёт — глагол в настоящем («Exploring…») с шиммером на заголовке, под ним один живой шаг со спиннером 14 и таймером; новый шаг проявляется 150 мс по opacity.
- **Мысль** — строка «Thought for 8s», «Thought briefly» без длительности или заголовок из текста («Planning the fix»); живая — «Thinking». Раскрытие — текст `ink-3`, не курсив.
- **Правка** — обычная строка шага 28: «Edited `session.ts` +N −M» (новый файл — «Created», счётчик показан только если > 0). Имя — кнопка, открывает правку в панели диффа (правый клик — меню файла). Шеврон появляется при hover/focus и раскрывает дифф прямо в ленте: блок `surface-2` радиус 12, max 240 с прокруткой внутри, unified, полоса 2px слева у изменённых строк, номера строк `ink-4`, подсветка слов, перенос по настройке wrap; патч грузится при раскрытии (скелетон). Идущая правка — только заголовок со спиннером и шиммером: содержимое правки до завершения не приходит.
- **Команда** — карточка `surface-2`: заголовок — описание от провайдера, иначе «Ran command»; справа «✓ 0» `ink-3` или «exit 1» `danger`, у идущей — таймер. Ниже `$ команда` mono в 2 строки (клик — целиком), «Show output» и копирование.
- **To-do** раскрывается в чек-лист. Ожидающее одобрение остаётся карточкой одобрения.
- **Завершённый ход** сворачивается в строку «Explored … · 46s»: 32, без фона в покое, `surface-2` радиус 8 при hover, длительность справа `tabular-nums`, без времени посередине.

## Запрос к пользователю (одобрение, вопрос, план)

- Карточка в потоке треда **над композером**: `surface`, радиус 20, `shadow-card`, слева сверху статус-пилюля `needs-you` («Approval needed»). Заголовок — что агент хочет сделать («Run `rm -rf dist`»), тело — команда/дифф/вопрос, низ — кнопки: `ghost Deny` → `secondary Always allow` → `primary Approve` (в этот момент primary композера неактивна — на экране всё равно одна).
- Вопрос с вариантами — радио-карточки; «Other» раскрывает поле.
- План на проверку — markdown-план в карточке `surface-2`, кнопки «Edit plan» (ghost) и «Implement plan» (primary).
- Клавиши: `Enter` — одобрить, `Esc` — отклонить; подписаны `kbd` на кнопках.

## Композер

- Над колонкой треда снизу, ширина = колонка 760 + 32. `surface`, радиус 24, `shadow-pop` (он «парит» над потоком), padding 12 12 8 16.
- Сверху — чипы контекста (файлы, изображения, PR, треды) с крестиком. Поле — `text-read`, авто-рост до 40% высоты листа, плейсхолдер `ink-4` «Ask Claude to…» (имя провайдера).
- Низ композера (высота 32): слева — выбор провайдера/модели (ghost `sm` со знаком провайдера), уровень рассуждений, режим (Chat/Plan), доступ (Supervised / Auto / Full access — с цветной точкой только у Full access `attention`), вложение «+»; справа — счётчик контекста (кольцо 16 + %, тултип), кнопка отправки — круг 32 `primary` со стрелкой вверх.
- Во время работы кнопка отправки → «Stop» (круг 32 `surface-3` с квадратом `ink`), а новое сообщение уходит в очередь (чип «Queued · 1» над полем).
- Фокус композера — кольцо как у поля (`inset 1px accent` + `4px accent-soft`).
- Перетаскивание файла — весь лист показывает зону `accent-soft` с пунктиром 1.5px `accent` (единственное исключение «без рамок») и текст «Drop to attach».

## Дифф

- Панель: тулбар 40 — сегмент Unified/Split, переключатель «Whole turn / Per file», поиск, ghost «Open in editor». Под ним — список файлов слева (220, строки 28: иконка статуса + путь с обрезкой посередине + `+N −M`) и содержимое справа.
- Файл: шапка 36 `surface` sticky — путь `text-code-sm` (имя 500 `ink`, папка `ink-3`) + `+N −M` + действия (copy path, свернуть). Код `text-code`, номера строк `ink-4` `tabular-nums`, фон добавленных/удалённых — `diff-add-bg`/`diff-del-bg`, слово — `*-word`. Свёрнутые неизменённые блоки — строка 28 `surface-2` «Show 24 hidden lines».
- Комментарий к строке (для агента) — плашка `surface-2` радиус 12 под строкой с полем и «Add to prompt».

## Терминал

- Поверхность `surface-2` радиус 12 (в ящике) или вся панель. Шрифт `text-code`, padding 12. Вкладки терминалов — `.ptabs` над ним; живой процесс — спиннер 12 на вкладке.
- Цвета ANSI выводятся из статусных и синтаксических токенов, фон всегда `surface-2` — терминал не «чёрный квадрат» в светлой теме.

## Палитра команд

- Модалка 640, радиус 28, `shadow-pop`, сверху 15vh. Поле поиска 52 без фона (на `surface`), `text-read`, лупа 18, `kbd Esc` справа. Под ним линия `line`.
- Группы (Threads, Projects, Actions, Settings, Theme) — подпись `text-caption`/500 `ink-3` без капса. Пункт 32 (`row-sm`, как в меню), радиус 8, иконка 16, текст, справа мета/`kbd`. Активный пункт (стрелки) — `surface-2`.
- Ничего не нашли — `.empty-row` «No results for “…”.». Низ палитры 32: подсказки клавиш `kbd` `text-caption` `ink-4`.
- Каждое действие из меню и кнопок доступно в палитре — проверяйте при добавлении фичи.

## Настройки

- Лист настроек: слева навигация 220 (группы: General, Agents, Workspace, Connections, Advanced — подписи `text-caption` `ink-3`, пункты 32 как в сайдбаре), справа колонка max 720: заголовок раздела `text-page` + строка «что здесь» `ink-3`, затем секции с заголовком `text-title` и отступом 32.
- Секция — плашка `surface-2` радиус 12 со строками внутри. Строка настройки: «подпись + подсказка слева — контрол справа», min-height 56 (`row-lg`), padding 12 16, разделитель `line` между строками. Переключатель/селект/сегмент применяются сразу; текстовые поля — автосохранение через 600 мс с индикатором «Saved» в заголовке секции.
- Опасные действия — последней секцией «Danger zone», кнопка `danger` → модалка подтверждения.
- Узкое окно: без раздела — список разделов строками 44 с шевронами; с разделом — только раздел и «All settings» сверху.

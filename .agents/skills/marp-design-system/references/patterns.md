# Паттерны

## Статусы агента

Пять семейств. Реальные состояния треда (`apps/web/src/components/Sidebar.logic.ts`) раскладываются по ним; слово — конкретное.

| Семейство   | Состояния продукта                                          | Цвет        | Иконка (Lucide)                                                   | Слово                                                        |
| ----------- | ----------------------------------------------------------- | ----------- | ----------------------------------------------------------------- | ------------------------------------------------------------ |
| `working`   | Working, Connecting, Waiting                                | `working`   | спиннер 14 (Connecting/Waiting — `loader` без вращения + слово)   | «Working · 2m 14s», «Connecting», «Waiting for terminal»     |
| `needs-you` | Pending Approval, Awaiting Input, Plan Ready, Guest Request | `attention` | `hand` / `message-circle-question` / `list-checks` / `user-round` | «Approval needed», «Question», «Plan ready», «Guest request» |
| `done`      | Completed (непрочитанный)                                   | `success`   | `check`                                                           | «Done»                                                       |
| `failed`    | Failed                                                      | `danger`    | `triangle-alert`                                                  | «Failed»                                                     |
| `idle`      | прочитанный завершённый, без сессии                         | `ink-4`     | нет (точка не рисуется)                                           | —                                                            |

- `needs-you` важнее всего: в сайдбаре такой тред поднимается в начало своего проекта, на свёрнутом сайдбаре точка на монограмме, в заголовке окна/док-иконке — счётчик.
- `done` гаснет в `idle`, как только тред открыт.
- Цвет статуса никогда не берётся из акцента.
- В строке сайдбара — компактная форма (точка 8 / спиннер 12), в шапке треда и в карточке запроса — пилюля со словом.

## Страница (не тред)

Pull requests, Usage, Settings, Welcome — на том же листе:

```
[Заголовок text-page]                         [secondary Действие] [primary Главное]
[строка ink-3 — что здесь]
                         ↓ 32
[секция: заголовок text-title + строка ink-3]
[контент секции]
```

- Отступ листа 32, колонка контента max 960 (настройки — 720). Между секциями 32.
- Фильтры страницы — сегментом или чипами справа в шапке.

## Таблица и список

- Список (PR, треды в архиве, устройства): строки 44 (`row-md`; с аватаром и действиями — 56 `row-lg`), разделитель `line`, hover `surface-2` со скруглением 8 (красятся ячейки, не `<tr>`). Первая колонка — объект (иконка/знак + название 500 + подпись `ink-3`), последняя — время или действия.
- Шапка таблицы 32 `surface-2` скруглённая плашка, `text-caption`/500 `ink-3`, без капса.
- Числа справа, `tabular-nums`. Время — относительное до суток («5m», «3h»), дальше дата «Oct 4».
- Строка кликабельна; редкие действия — «⋯».

## Пустые состояния

Тип отвечает «почему пусто», размер — «где пусто».

| Тип                                            | Плитка                              | Кнопка                                                      |
| ---------------------------------------------- | ----------------------------------- | ----------------------------------------------------------- |
| Ещё ничего нет («No threads yet»)              | `accent-soft`, предмет раздела      | создаёт первое: «New thread»                                |
| Нужно подключить («Connect a provider»)        | `accent-soft`                       | «Connect provider», «Add project»                           |
| Ничего не нашли (поиск, фильтр)                | `surface-2` / `ink-3`, лупа         | «Clear filters»; для поиска — без кнопки, запрос в кавычках |
| Ещё не пришло (синхронизация, ожидание PR, CI) | `surface-2` / `ink-3`, часы         | нет; срок цифрой, если известен                             |
| Всё сделано («All caught up»)                  | `success-soft` / `success`, галочка | нет или ghost                                               |

| Размер            | Где                                                        | Отступы | Плитка                   | Кнопка                                     |
| ----------------- | ---------------------------------------------------------- | ------- | ------------------------ | ------------------------------------------ |
| Страница          | вместо содержимого листа (нет проектов, пустой новый тред) | 64 / 24 | 44, радиус 14, иконка 20 | 36; primary, если главное действие раздела |
| Панель / карточка | правая панель, карточка, модалка                           | 32 / 20 | 36, радиус 12, иконка 16 | 28, secondary                              |
| Строка            | поповер, палитра, список в сайдбаре                        | 16 / 12 | нет                      | подчёркнутая ссылка в строке               |

- Пустой новый тред — не пустое состояние, а приглашение: композер по центру листа, над ним `text-hero` «What should we build?» (имя проекта под ним `ink-3`), под композером 3 недавних действия проекта ghost-чипами. Без иллюстраций.
- Нет права — не пустота: нейтральная плашка «Only the environment owner can change this» + кто владелец.
- Не загрузилось — не пустота: блок ошибки с «Retry».

## Без тупиков

- Пустой раздел не прячет подготовку: нет провайдера → кнопка подключения прямо в композере; нет проекта → «Add project» и «Clone repository» на месте; нет ветки → создать из выбора ветки.
- Если действию чего-то не хватает (нет авторизации провайдера, окружение офлайн, нет git-remote) — на месте объяснение и путь к исправлению с возвратом обратно.
- Проверка: пройти сценарий с нуля — свежая установка, ни одного проекта и провайдера — и дойти до первого ответа агента без внешних подсказок.

## Загрузка и ошибки

- Первая загрузка — скелетон той же формы, статичный (без шиммера). Обновление поверх показанного — без скелетона, контент не прыгает.
- Ошибка блока — внутри блока: что не загрузилось + «Retry». Не роняйте весь экран из-за одного блока.
- Потеря соединения с окружением — баннер над листом «Reconnecting to MacBook Pro…» (`notice`), после 30 с — `warning` с «Retry now»; композер остаётся доступен, сообщение уходит в очередь.
- Ошибка провайдера в ходе — карточка `danger-soft` в потоке треда: что случилось человеческим языком + исходный текст ошибки свёрнутым `text-code-sm` + «Retry turn».

## Соединения и окружения

- Окружение (локальное, удалённое, туннель) всегда подписано в сайдбаре: знак машины + имя + точка соединения (`success` — на связи, `attention` — переподключается, `danger` — офлайн).
- Тред на удалённом окружении показывает чип окружения в шапке. Действия, недоступные удалённо, — выключены с тултипом «почему».

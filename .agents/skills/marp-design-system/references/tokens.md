# Токены

Источник: блок `:root` / `[data-theme="dark"]` / `[data-accent]` в `docs/design/assets/reference.css`. Меняются только там (потом — в `apps/web/src/index.css`). Таблицы ниже — копия для быстрого поиска.

## Типографика — Onest + JetBrains Mono

## Акцент — личная настройка

`data-accent` на `<html>` переопределяет шесть ролей `accent*` и кольцо фокуса для обеих тем. Набор (`ACCENTS` в `docs/design/assets/reference.js`):

| id         | Название             | Светлая   | Тёмная    | Текст на акценте (светлая) |
| ---------- | -------------------- | --------- | --------- | -------------------------- |
| `clay`     | Глина (по умолчанию) | `#b4532f` | `#ee8a64` | белый                      |
| `forest`   | Лес                  | `#27804a` | `#52cf8b` | белый                      |
| `iris`     | Ирис                 | `#6250d8` | `#a395ff` | белый                      |
| `sky`      | Небо                 | `#2a6cc4` | `#71abff` | белый                      |
| `teal`     | Бирюза               | `#127f74` | `#45c9b9` | белый                      |
| `amber`    | Янтарь               | `#d99a1e` | `#f3b94d` | тёмный `#2b1d03`           |
| `peony`    | Пион                 | `#bd3d7a` | `#f17bb4` | белый                      |
| `graphite` | Графит               | `#34312d` | `#e9e4dc` | белый (в тёмной — тёмный)  |

Правила: текст на акценте ≥ 4.5:1 в обеих темах, текст на мягком фоне ≥ 4.5:1, акцент на `surface` ≥ 3:1. Палитра статусов и подсветки синтаксиса от акцента **не зависит**. «Небо» близко к `working` — допустимо, статус всегда идёт с иконкой и словом.

## Словарь: эталон → утилита в `apps/web`

Переносится в `index.css` при реализации; до тех пор новые компоненты по эталону используют эти имена.

| Эталон                                       | Утилита                                                                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bg` / `surface` / `surface-2` / `surface-3` | `bg-background` / `bg-card` (`bg-popover`) / `bg-muted` / `bg-surface-hover`                                                                           |
| `ink` … `ink-4`                              | `text-foreground` / `text-foreground-secondary` / `text-muted-foreground` / `text-foreground-subtle`                                                   |
| `line`                                       | `border-border`, `bg-border` (разделители)                                                                                                             |
| `accent*`                                    | `bg-primary`, `hover:bg-primary-hover`, `text-primary-foreground`, `bg-primary-soft`, `text-primary-soft-foreground`                                   |
| статусы                                      | `text-working`, `bg-working-soft`, `text-attention`, `bg-attention-soft`, `text-success`, `bg-success-soft`, `text-destructive`, `bg-destructive-soft` |
| тултип, тост                                 | `bg-inverse text-inverse-foreground`                                                                                                                   |
| радиусы                                      | `rounded-item` (8) / `rounded-field` (12) / `rounded-card` (20) / `rounded-composer` (24) / `rounded-panel` (28) / `rounded-pill`                      |
| тени                                         | `shadow-card` / `shadow-pop` / `shadow-raised`                                                                                                         |
| контролы                                     | `h-control` / `h-control-sm`, `h-row`, `h-table-row`, `h-table-head`                                                                                   |
| шрифт                                        | `text-caption` / `text-body` / `text-read` / `text-title` / `text-heading` / `text-page` / `text-hero` / `text-code` / `text-code-sm`                  |
| движение                                     | `transition-colors-fast`, `transition-enter`, `ease-out-soft`, `ease-spring-soft`                                                                      |

shadcn `bg-accent` — это hover-заливка (= `surface-3`), **не** акцент. Акцент всегда `primary`.

Запрещено в компонентах: hex, `rgb()`, цвета в `style={{}}`, произвольные значения `[13px]`, `rounded-[10px]`, `shadow-[…]`, `border` на поверхностях, `text-xs/sm/base/lg`, `rounded-xl/2xl/3xl`, `text-gray-*`, `bg-white`.
